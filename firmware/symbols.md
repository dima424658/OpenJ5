# Символы J5V05L19

Для подтверждённых имён записываем адрес, инструкцию или ссылку из кода и, где применимо, калибровку и раздел руководства. Для гипотез указываем адрес в имени и какой факт нужен для подтверждения. Все адреса `CODE` соответствуют смещениям в штатном BIN.

## Подтверждённые участки

| Адрес | Имя | Основание |
|---|---|---|
| `CODE:0000` | `reset_vector` | Инструкция `LJMP` ведёт к `reset_entry_204d`. |
| `CODE:0003`, `001B`, `0023`, `006B` | `irq_vector_0003`, `irq_vector_001b`, `irq_vector_0023`, `irq_vector_006b` | Векторы переходят на `078C`, `04B4`, `5A25`, `0119` соответственно. `0023` — вектор UART0. |
| `CODE:000B`, `0013`, `002B`, `0043`, `004B`, `0053`, `005B`, `0063`, `0083`, `0093`, `009B`, `00A3`, `00AB` | `irq_unused_<адрес>` | Каждый вектор выполняет ровно один `RETI`. SDCC генерирует его из пустой функции C с атрибутом `__interrupt`. |
| `CODE:A575–A59C` | `interp_curve_q4` | Преобразует координату 4.4 из `R2` в индекс `R3` из пяти старших битов и дробную часть `R2` из трёх младших. При нулевой дроби читает один узел, иначе вычисляет взвешенную сумму соседей. По `4351` читает коэффициент уставки РХХ по оборотам, по `544D` использует координату циклового наполнения. |
| `CODE:A59D–A5FE` | `interp_bilinear_u8` | Реализация на C. Два индекса 4.4 в `R2` и `R3`, указатель на таблицу CODE в `DPTR`, сырой результат в `A`. Вызовы по `383F` и `3FA8` используют базовое цикловое наполнение и таблицы экономичного либо соседнего варианта УОЗ. |
| `CODE:A5FF–A610` | `blend_u8_q8` | Смешивает байты `R0` и `R2` по весу `R3`. Результат в `A` равен старшему байту суммы двух произведений. Дополнительный вес вычисляется по модулю 256, поэтому при `R3=0` результат равен нулю. Вызов по `A74B` смешивает значения УОЗ, используя вес из `XDATA:F87B`. |
| `CODE:A611–A62E` | `interp_curve_u8` | Реализация на C. Индекс в `R2`, дробная часть в `R3`, указатель в `DPTR`, результат в `A`. Вызов по `42A0` использует кривую желаемых оборотов ХХ. Возрастающая ветвь округляет приращение, убывающая отбрасывает дробь. |
| `CODE:A62F–A69A` | `interp_bilinear_xdata` | Та же арифметика, что по `A59D`. Старший байт `DPTR` задаёт страницу XDATA, младший заменяется смещением ячейки. Вызов по `489A` выбирает страницу `FD00` или `FE00`. |
| `CODE:A6CD–A6EE` | `interp_descending_curve_q4` | Интерполирует убывающую кривую по координате Q4.4 в `A` и указателю `DPTR`. Читает пару соседних байтов, умножает их разность по модулю 256 на дробную часть, отбрасывает дробь и вычитает поправку из левой точки с насыщением на нуле. Вызов по `4A53` использует кривую накопления катушек. |
| `CODE:2291–2327` | `check_startup_ram`, `validate_startup_ram`, `clear_startup_ram`, `reset_startup_ram_fields` | Метка `F8C2=55` ведёт сразу к сбросу шести полей. При другой метке бит 1 `F9B0` разрешает принять сохранённое состояние. Иначе код сравнивает 16-битную сумму `1 + sum(FD00–FEFF) + sum(F4D2–F511)` с `F8FE–F8FF` и устанавливает бит `16` при несовпадении. Обе ветви после проверки очищают диапазоны `FF00–FF83`, `F900–F933`, `F800–F8FF` и поле `F4B8`, затем сбрасывают те же шесть полей. |
| `CODE:2328–240D` | `continue_startup_calibrations`, `restore_startup_knock_noise`, `seed_startup_knock_filters` | Загружает начальный порог детонации, фазы окна измерения и интервалы. При восстановлении принимает уровень `FFCE` выше сырого порога 16 и не выше удвоенного начального значения в байте. Для сохранённого аттенюатора проверяет предел 24. При неверном аттенюаторе средние значения уже записаны, а сумма фильтра инициализируется начальным уровнем. Если по флагам требуется начальная установка, код записывает 8 в `IRAM:47` и сам начальный уровень в `FFCF`. Пять 16-битных сумм фильтра получают младший байт 0 и старший байт `FFCE >> 1`. [Контроль детонации, стр. 48–51](../docs/ctp321.pdf#page=48) |
| `CODE:240E–2473` | `continue_startup_attenuation`, `init_knock_filter_frequency` | Биты 3–4 состояния аттенюатора выбирают множитель 1, 2 или 4. Сохранённый уровень шума умножается с насыщением до 255, затем старшие пять бит выбирают коэффициент порога из `8F2A`. Для начального порога код умножает исходный шум на коэффициент Q4, отбрасывает четыре младших бита и ограничивает результат до 255. Калибровка `5F9C` задаёт точку частоты фильтра, таблица `8A59` даёт код для `F931`. [Алгоритм определения детонации, стр. 48–50](../docs/ctp321.pdf#page=48) |
| `CODE:2474–252A` | `configure_knock_filter` | Передаёт шесть команд в штатном порядке. Вторая содержит начальный индекс фильтра из `5F9C`. Для пятой устанавливает бит 2 команды `5F9E`, ждёт завершения преобразования АЦП на канале 7 и сохраняет в `IRAM:42` результат с ограничением сверху до 30. Шестая команда берётся из `5F9E` без добавления бита. Между операциями сохраняются переключения `P1.4`, бита 5 `SFR:F9` и вызовы задержки. [Настройка полосового фильтра](../docs/ctp321.pdf#page=48) |
| `CODE:ACEA–AD94` | `send_knock_command`, `wait_knock_filter` | Передаёт восемь битов регистра `B`, начиная со старшего. В `SFR:F9` бит 7 передаёт данные, а бит 4 формирует такт. После каждого фронта выполняется одна инструкция `NOP`. По `AD63` выполняется штатная задержка из 49 инструкций `NOP` перед возвратом. |
| `CODE:252B–26D1` | `continue_startup_config` | Загружает флаги комплектации из `6051–6052` в `IRAM:20–21`. Штатная инструкция по `2530` устанавливает бит 0 первого байта. Загружает начальную фазу впрыска, коэффициент динамической коррекции циклового наполнения и температуру точки росы ОГ. Инициализирует рабочие поля, включая счётчик низкого напряжения `FA78`, метку сервисного сохранения `F9A3` и состояние шагового привода РХХ. [Карта 0738](../bins/J5V05L19_738.j5) |
| `CODE:26D2–277D` | `init_startup_control_state`, `configure_startup_output_bits` | Загружает начальный состав смеси, положение ДПДЗ и коррекцию времени впрыска. Калибровка минимального расхода для диагностики ДМРВ записывается в `TL0` дважды, как в штатном коде. Биты комплектации адсорбера и рециркуляции переносятся в биты 6–7 `SFR:F6`. Вызывает инициализацию режима пуска и при установленном бите `15`, бите 1 `F9B0` или ошибке суммы ОЗУ вызывает восстановление начальной карты коррекции и задаёт начальный коэффициент `0x80`. [Карта 0738](../bins/J5V05L19_738.j5) |
| `CODE:277E–27D2` | `continue_startup_fuel_trim`, `init_startup_baro_history` | Ограничивает сохранённый KGBC в `FFC0` диапазоном из `5F97–5F98` и заполняет им 32 ячейки истории `F8D0–F8EF`. Состояние из `F4D2–F511` очищается, если сброшен бит 0 калибровки `60DE` или установлен один из трёх признаков сброса. Затем в любом случае фильтруются записи и обнуляются `F4D8` и `F518`. [Карта 0738](../bins/J5V05L19_738.j5) |
| `CODE:27D3–280D` | `sample_startup_coolant` | Измеряет канал 4 АЦП, записывает отсчёт в `F80B` и интерполирует тарировку `6104` с шагом 8 кодов АЦП. Из результата вычитает 20 с ограничением снизу нулём. Сохраняет температурный код в `IRAM:49` и `F9B5` и выбирает температурный индекс для прогрева с ограничением до 36. При дробной координате последнего индекса штатная интерполяция читает соседний байт по `6124`. [Карта 0738](../bins/J5V05L19_738.j5) |
| `CODE:9DAC–9DC7`, `CE94–CEAE` | `reset_fuel_correction_map`, `clear_retained_words_ce94` | Первая процедура копирует 256 байтов калибровки начальной коррекции впрыска `6813` в `XDATA:FD00–FDFF`. Вторая заполняет значением из `A` два диапазона по 64 байта, начиная с `F512` и `F552`. Обе переключают `DPSEL` между банками 0 и 2 и оставляют выбранным банк 0. [Топливоподача, стр. 36](../docs/ctp321.pdf#page=36) |
| `CODE:2818–28B4` | `warmup_setup_continue`, `sample_startup_voltage`, `init_injector_voltage_offset` | Измеряет ДПДЗ на канале 3, вычитает ноль, применяет коэффициент `6068` и предел `606A`. Для напряжения с канала 1 принимает сырой отсчёт в диапазоне `[60BA, 60BB)`, вне диапазона берёт аварийное значение `60BF`. Из выбранного кода вычитает смещение `60BC` с ограничением снизу, применяет коэффициент Q7 из `60BD` с насыщением до 255 и интерполирует поправку форсунок по таблице `71D8`. [Карта 0738](../bins/J5V05L19_738.j5) · [Расчёт топливоподачи, стр. 36](../docs/ctp321.pdf#page=36) |
| `CODE:28B5–28F6` | `continue_startup_sensor_setup`, `init_startup_iac_offset` | Принимает исходный отсчёт ДМРВ с канала 0 АЦП, если он в диапазоне 40…59. Порог диагностики ДПКВ получает этот отсчёт плюс сырое смещение `5FA6` по модулю 256. При любом отсчёте начальное смещение РХХ выбирается из `8C00` по температурному индексу. [Карта 0738](../bins/J5V05L19_738.j5) |
| `CODE:28F7–295D` | `continue_startup_sensor_mode` | При установленном флаге адсорбера выбирает холодную продувку ниже 50 °C и горячую от 50 °C. Холодная ветвь копирует 256 байтов из `FD00–FDFF` в `FE00–FEFF`. Горячая ветвь обновляет вторую карту при признаке переинициализации и прибавляет к исходным байтам поправку `76EF` по модулю 256. [Пусковая подготовка карт коррекции, стр. 41](../docs/ctp321.pdf#page=41) |
| `CODE:295E–298F` | `enable_startup_timers`, `select_startup_iac_position` | Запускает Timer 1 с исходным значением `FACB` и настраивает прерывания. При метке `F8C2=55` восстанавливает сохранённое положение РХХ. При другой метке ошибка суммы ОЗУ вызывает сброс сохранённого состояния, а ошибка суммы или бит 1 `F9B0` направляют к полному позиционированию по `2990`. |
| `CODE:29D0–2A49` | `continue_startup_after_iac`, `update_startup_ign_flags`, `load_cycle_configuration` | После импульса по `A962` включает прерывания и ждёт события `48`. Для коррекции УОЗ холодного двигателя использует гистерезис по биту 1 `F87F`: при выключенной коррекции включает её ниже 60 °C, при включённой отключает от 68 °C. Далее сохраняет флаги предыдущего режима, перечитывает комплектацию и обновляет фазы измерения детонации по половинному индексу оборотов `IRAM:58`. Маски `0x20` и `0x40` в `IRAM:7B` удерживают соответствующие фазы. [Карта 0738](../bins/J5V05L19_738.j5) |
| `CODE:2A4A–2A90` | `apply_knock_window_phases` | Ограничивает обе фазы до 29, затем преобразует каждую в `(фаза − 11) mod 30` и вычисляет вторую сдвинутую на 15 отсчётов фазу. Записывает четыре результата в `IRAM:56`, `74`, `4A` и `4C` при отключённых прерываниях, затем включает прерывания. [Контроль детонации, стр. 48–50](../docs/ctp321.pdf#page=48) |
| `CODE:2A91–2AC8` | `continue_cycle_fuel` | При температуре ОЖ выше сырого порога `5F8D` умножает 16-битный вклад динамики подачи `F97B–F97C` на коэффициент `5F8B` в Q8, отбрасывает дробь и ограничивает запаздывание УОЗ пределом `5FAA`. При равенстве порогу и ниже него в `F938` записывается 0. [Динамическая коррекция УОЗ, стр. 44](../docs/ctp321.pdf#page=44) |
| `CODE:2AC9–2B1A` | `check_crank_activity`, `sample_crank_period` | Атомарно считывает и сбрасывает бит события `35`. Без события увеличивает счётчик с насыщением до 255. От 22 циклов выставляет признак остановки и обнуляет расчётные обороты. После события признак снимается, если до него прошло меньше 11 циклов. Для расчёта оборотов считывает период из `IRAM:38–39` при отключённых прерываниях. |
| `CODE:2B1B–2B41` | `calculate_rpm_from_period` | Записывает делимое 1 000 000 в `SFR:E9–EC`, период в `ED–EE` и ждёт шесть инструкций `NOP`. Считывает результат в `R3:R2:R1:R0` и завершает чтение регистров делителя. Если установлен бит `44`, возвращается к считыванию периода. |
| `CODE:2B42–2B9D` | `scale_crank_rpm_result` | Ограничивает частное до 16 бит. Записывает округлённые `(q + 1) / 2` и `(q + 4) / 8` с насыщением до 255 в `IRAM:53` и `IRAM:55`. В `XDATA:FA5E` сохраняет прирост второго значения с учётом переноса округления и нижней границей 0. В `XDATA:F8AF` сохраняет значение с верхней границей 31. |
| `CODE:2B9E–2BCC` | `publish_crank_rpm_axis_code` | Делит `q + 3` на 6 через MDU после четырёх `NOP` и повторяет операцию при бите `44`. Записывает код оси оборотов в `IRAM:54` с насыщением до 255. Переполнение при прибавлении 3 сразу даёт 255. |
| `CODE:2990–29CF` | `home_and_seed_iac_feedback`, `restore_startup_iac_position`, `seed_startup_iac_feedback` | Ветвь по `2990` полностью позиционирует РХХ. По `2995` восстанавливается счётчик шагов из `XDATA:F9AF`, а уставка выбирается по температуре. В обеих ветвях начальная уставка переводится в Q4 для регулятора и записывается метка `0x55` в `F8C2`. |
| `CODE:3AEA–3B26` | `update_engine_stop_counters`, `dispatch_engine_shutdown`, `reset_engine_stop_counters` | По секундному событию увеличивает счётчики `F807` и, при сброшенном бите `53`, `F9BE`. Счётчики насыщаются на 255. Бит `4D` направляет в фазу ожидания, бит `4C` запускает проверку ключа. Ветка по `3B0B` очищает суммы измерений и счётчики, затем сбрасывает ожидание остановки. |
| `CODE:3B27–3BB0` | `begin_ignition_shutdown`, `read_supply_during_shutdown`, `service_pending_shutdown` | После истечения интервала `60AA` отключает выходы двигателя, выставляет `4D` и запускает парковку РХХ. Обслуживание фазы уменьшает `FA76`, не записывая уменьшенное значение при результате 0. В зависимости от `F47D` и `F4B7` затем проверяет задержку `60C9` или ветвится к сохранению состояния. Повторный отсчёт АЦП от порога `60CA` также ведёт к сохранению состояния и дальнейшей проверке питания. [Остановка двигателя, стр. 52–53](../docs/ctp321.pdf#page=52) |
| `CODE:3BB1–3C2A` | `save_shutdown_state`, `sum_retained_ram`, `recheck_shutdown_supply` | Перед отключением сохраняет два признака в `F9AD` и `FFCF`, фильтрует записи через `AC2D` и считает 16-битную сумму с начальным значением 1 по диапазонам `FD00–FEFF` и `F4D2–F511`. Результат хранится в `F8FE–F8FF`, младший байт первым. По `22A2–22DC` запуск проверяет ту же сумму и сообщает о несовпадении битом `16`. После сохранения отсчёт АЦП от порога ведёт к перезапуску `204D`. При низком отсчёте очищается метка пуска РХХ и начинается подготовка выходов к отключению. [Остановка двигателя, стр. 52–53](../docs/ctp321.pdf#page=52) |
| `CODE:3C2B–3C8A` | `continue_power_down`, `persist_shutdown_data`, `wait_for_power_removal` | Проверяет младшую тетраду `F942` и в зависимости от результата читает метку `FA79` либо бит 1 `F9B0`. По этому условию вызывает запись метки `0x55` в EEPROM. Затем вызывает процедуры сохранения и сверки блоков, в том числе условный блок по биту `6A`. В конце записывает `0xAA` в `F9AC` и `0xA5` в косвенно адресуемый `IRAM:A8`, поднимает `P1.7` и остаётся в цикле установки `IE.6` и `IP.6`. |
| `CODE:ABCA–AC04` | `stop_engine_outputs` | Сбрасывает `IP.5`, биты 5 и 6 в `F999` и флаг событий `31`. Переводит регистры управления выходами в состояние остановки и обнуляет обороты и индексы оси в `IRAM:53–55`, `57` и `58`. [Остановка двигателя, стр. 52–53](../docs/ctp321.pdf#page=52) |
| `CODE:518F–521A` | `check_service_save_request`, `park_iac_for_service`, `save_service_state`, `save_service_ram_checksum` | Сервисный цикл проверяет биты `69`, `79` и бит 5 косвенно адресуемого `IRAM:91`. Бит `56` дополнительно требует довести РХХ до максимального положения и отключить выходы двигателя перед сохранением. Затем код записывает метку `FF` через `C079`, сбрасывает сохраняемое состояние и вызывает процедуры EEPROM. Сумма ОЗУ считается по тем же диапазонам, что при обычном выключении. ## Рабочие гипотезы и следующий разбор

| Адрес | Предложенное имя | Критерий подтверждения |
|---|---|---|
| `IRAM:0049` | `coolant_temp_raw_49` | Значение используется при расчёте индекса температурной кривой ХХ. Проследить все записи в этот байт до преобразования показания ДТОЖ. |
| `IRAM:0062` | `ignition_lookup_raw_62` | В байт записывается результат интерполяции ветви УОЗ по `3FAB`. Проследить последующие чтения и установить, к какому промежуточному значению относится байт после переключения таблиц. |
| `IRAM:002F` (бит 4) | `diagnostic_reply_ready_2f_4` | Одна ветвь перед установкой флага загружает указатель на диагностический ответ `CODE:C852`. Проверить назначение всех установок и сбросов флага и место начала передачи. |

Для ветвей пуска, перехода на ХХ и рабочей топливоподачи начинать с поиска обращений к калибровкам одноимённых групп J5. Сопоставлять ветвления, флаги комплектации и масштаб арифметики с руководством. Описание Январь‑5 задаёт рабочие гипотезы для L19.
