# Символы J5V05L19

Для подтверждённых имён записываем адрес, инструкцию или ссылку из кода и, где применимо, калибровку и раздел руководства. Для гипотез указываем адрес в имени и какой факт нужен для подтверждения. Все адреса `CODE` соответствуют смещениям в штатном BIN.

## Подтверждённые участки

| Адрес | Имя | Основание |
|---|---|---|
| `CODE:0000` | `reset_vector` | Инструкция `LJMP` ведёт к `reset_entry_204d`. |
| `CODE:0003`, `001B`, `0023`, `006B` | `irq_vector_0003`, `irq_vector_001b`, `irq_vector_0023`, `irq_vector_006b` | Векторы переходят на `078C`, `04B4`, `5A25`, `0119` соответственно. `0023` — вектор UART0. |
| `CODE:A59D–A5FE` | `interp_bilinear_u8` | Два индекса 4.4 в `R2` и `R3`, указатель на таблицу в `DPTR`, сырой результат в `A`. Вызовы по `383F` и `3FA8` используют базовое цикловое наполнение и таблицы экономичного либо соседнего варианта УОЗ. |
| `CODE:A611–A62E` | `interp_curve_u8` | Индекс в `R2`, дробная часть в `R3`, указатель в `DPTR`, результат в `A`. Вызов по `42A0` использует кривую желаемых оборотов ХХ. Возрастающая и убывающая ветви округляют по-разному. |
| `XDATA:F887`, `F888` | `idle_temp_index`, `idle_temp_fraction` | Блок по `33A7` ограничивает индекс сверху числом 36 и умножает остаток деления сырого кода температуры на 51. Оба значения читаются перед вызовом по `42A0`. |
| `CODE:CD7C–CD7E` | `set_flag_2f_4_cd7c` | `SETB` устанавливает бит 4 в `IRAM:2F`, затем `RET`. Сюда ведут переходы по `CCE7` и `CCFB`. Реализация на C. |
| `CODE:D2F1–D2F3` | `set_flag_2f_7_d2f1` | `SETB` устанавливает бит 7 в `IRAM:2F`, затем `RET`. Сюда ведёт переход по `321B`. Реализация на C. |
| `CODE:F275–F277` | `clear_flag_21_0_f275` | `CLR` сбрасывает бит 0 в `IRAM:21`, затем `RET`. Сюда ведут переходы по `F07C`, `F0D8`, `F173` и `F272`. Реализация на C. |
| `CODE:60C7`, `60C8` | `fan_off_temperature`, `fan_on_temperature` | Карта 0738 и чтения по `4B2F` и `4B38` дают пороги выключения и включения вентилятора. Два C-значения в градусах кодируются как `T + 40`. |

## Сверка карт и руководства

Адреса и подписи взяты из обычной карты [0738](../bins/J5V05L19_738.j5). Для каждой строки найдена запись с теми же типом, ID и размерами в обычной карте [0923](../bins/J5v05l19_0923.j5). Смещения записей начинаются с их заголовков CTM.

| Калибровка | CODE и ID | Сопоставление | Где читать алгоритм |
|---|---|---|---|
| Желаемые обороты | `6F56`, `D51CF610` | Кривая `desired_idle_rpm` в C из 39 точек, температура ОЖ → обороты. CTM `633D` в 0738, `6047` в 0923. `MOV DPTR,#0x6F56` по `429D`. | [Холостой ход, стр. 32–33](../docs/ctp321.pdf#page=32) |
| Базовое цикловое наполнение | `75EF`, `4E7F9E27` | Таблица `base_cylinder_charge_raw` в C размером 16 × 16, обороты и положение дросселя → мг/цикл. CTM `C3A6` и `BAEB`. `MOV DPTR,#0x75EF` по `383C`. | [Расчёт циклового наполнения, стр. 45](../docs/ctp321.pdf#page=45) |
| УОЗ для экономичного режима | `6AC8`, `3228799F` | Таблица `economy_ignition_half_degrees` в C размером 16 × 16, обороты и цикловое наполнение → градусы поворота коленвала. CTM `CC2C` и `C32E`. `MOV DPTR,#0x6AC8` по `3F95`. | [УОЗ в рабочих режимах, стр. 43](../docs/ctp321.pdf#page=43) |

Формат значений в карте описывает представление в редакторе. В частности, УОЗ показывается как знаковое значение, а `interp_bilinear_u8` обрабатывает сырые байты как беззнаковые. [Разбор карт J5](../docs/calibrations.md#кривые-и-таблицы-в-0738)

## Рабочие гипотезы и следующий разбор

| Адрес | Предложенное имя | Критерий подтверждения |
|---|---|---|
| `IRAM:0049` | `coolant_temp_raw_49` | Значение используется при расчёте индекса температурной кривой ХХ. Проследить все записи в этот байт до преобразования показания ДТОЖ. |
| `IRAM:0062` | `ignition_lookup_raw_62` | В байт записывается результат интерполяции ветви УОЗ по `3FAB`. Проследить последующие чтения и установить, к какому промежуточному значению относится байт после переключения таблиц. |
| `IRAM:002F` (бит 4) | `diagnostic_reply_ready_2f_4` | Одна ветвь перед установкой флага загружает указатель на диагностический ответ `CODE:C852`. Проверить назначение всех установок и сбросов флага и место начала передачи. |

Для ветвей пуска, перехода на ХХ и рабочей топливоподачи начинать с поиска обращений к калибровкам одноимённых групп J5. Сопоставлять ветвления, флаги комплектации и масштаб арифметики с руководством. Описание Январь‑5 задаёт рабочие гипотезы для L19. Например, раздел диагностики прямо отмечает, что часть флагов зависит от версии ПО и норм токсичности.
