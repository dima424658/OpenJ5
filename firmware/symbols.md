# Символы J5V05L19

Для подтверждённых имён записываем адрес, инструкцию или ссылку из кода и, где применимо, калибровку и раздел руководства. Для гипотез указываем адрес в имени и какой факт нужен для подтверждения. Все адреса `CODE` соответствуют смещениям в штатном BIN.

## Подтверждённые участки

| Адрес | Имя | Основание |
|---|---|---|
| `CODE:0000` | `reset_vector` | Инструкция `LJMP` ведёт к `reset_entry_204d`. |
| `CODE:0003`, `001B`, `0023`, `006B` | `irq_vector_0003`, `irq_vector_001b`, `irq_vector_0023`, `irq_vector_006b` | Векторы переходят на `078C`, `04B4`, `5A25`, `0119` соответственно. `0023` — вектор UART0. |
| `CODE:000B`, `0013`, `002B`, `0043`, `004B`, `0053`, `005B`, `0063`, `0083`, `0093`, `009B`, `00A3`, `00AB` | `irq_unused_<адрес>` | Каждый вектор выполняет ровно один `RETI`. SDCC генерирует его из пустой функции C с атрибутом `__interrupt`. |
| `CODE:A575–A59C` | `interp_curve_q4` | Преобразует координату 4.4 из `R2` в индекс `R3` из пяти старших битов и дробную часть `R2` из трёх младших. При нулевой дроби читает один узел, иначе вычисляет взвешенную сумму соседей. По `4351` читает коэффициент уставки РХХ по оборотам, по `544D` использует координату циклового наполнения. |
| `CODE:A59D–A5FE` | `interp_bilinear_u8` | Реализация на C. Два индекса 4.4 в `R2` и `R3`, указатель на таблицу CODE в `DPTR`, сырой результат в `A`. Вызовы по `383F` и `3FA8` используют базовое цикловое наполнение и таблицы экономичного либо соседнего варианта УОЗ. |
| `CODE:A5FF–A610` | `blend_u8_q8` | Смешивает байты `R0` и `R2` по весу `R3`. Результат в `A` равен старшему байту суммы двух произведений. Дополнительный вес вычисляется по модулю 256, поэтому при `R3=0` результат равен нулю. Вызов по `A74B` смешивает значения УОЗ, используя вес из `XDATA:F87B`. |
| `CODE:A611–A62E` | `interp_curve_u8` | Реализация на C. Индекс в `R2`, дробная часть в `R3`, указатель в `DPTR`, результат в `A`. Вызов по `42A0` использует кривую желаемых оборотов ХХ. Возрастающая ветвь округляет приращение, убывающая отбрасывает дробь. |
| `CODE:A62F–A69A` | `interp_bilinear_xdata` | Та же арифметика, что по `A59D`. Старший байт `DPTR` задаёт страницу XDATA, младший заменяется смещением ячейки. Вызов по `489A` выбирает страницу `FD00` или `FE00`. |
| `CODE:A22E–A239` | `clear_iac_history` | Обнуляет десять байтов `XDATA:F851–F85A`. Вызовы по `4B63` и `4CA0` следуют за изменением уставки РХХ. На выходе `R1=0`, `A=0` и `DPTR=F85B`. |
| `CODE:2041–204C` | `clear_fuel_history_f839` | Обнуляет восемь байтов `XDATA:F839–F840`. Вызывается из ветки отсечки по `4607`. На выходе `R0=0`, `A=0`, `DPTR=F841`, перенос сохранён. |
| `CODE:A314–A324` | `clamp_stock_u8` | Ограничивает беззнаковый байт в `A` нижней границей `R0` и верхней `R1`, проверяя нижнюю первой. `CY` установлен при выходе за границу или равенстве верхней границе. Прямой вызов есть по `1C42`. |
| `CODE:A325–A339` | `limit_stock_i8_by_sign` | Проверяет только нижнюю границу для отрицательного входа и только верхнюю для неотрицательного. `CY` установлен для всех отрицательных входов и при достижении верхней границы. Прямой вызов есть по `49E3`. |
| `CODE:A33A`, `A346` | `minimum_u16_register_pair`, `maximum_u16_register_pair` | Беззнаковое сравнение `R3:R2` с `R1:R0` и запись минимума или максимума в `R1:R0`. `CY` хранит заём от сравнения. Вызовы по `17B3` и `2EB9` используют результат при записи в XDATA. |
| `CODE:A352–A363`, `A364–A380` | `multiply_stock_u16_u8`, `multiply_stock_i16_u8` | Умножают беззнаковое или знаковое слово `R1:R0` на беззнаковый байт `B`. 24-битное произведение возвращается в `R1:R0:B`, старший байт также в `A`. Вызов по `3FD4` использует беззнаковую версию для порога детонации, по `9E82` вызывается знаковая версия. |
| `CODE:A381`, `A389` | `negate_u16_register_pair`, `negate_u24_register_triple` | Два или три последовательных вычитания с заёмом вычисляют отрицание по модулю разрядности, начиная с `R0`. Для 16-битного варианта есть вызовы по `0FC6` и `2E6E`. Для 24-битного варианта прямой вызов пока не найден. |
| `CODE:A394`, `A408` | `sign_extend_i24_register_triple`, `sign_extend_i8_register` | Знак старшего входного байта расширяется в следующий регистр. По `A05F` из `R2` формируется `R3` для 16-битного сложения сразу следом. По `9F55` расширяется `R0` в `R1` перед умножением. |
| `CODE:A39E`, `A3AC`, `A3BA`, `A3C8` | `shift_left_saturating_1` … `shift_left_saturating_4` | Сдвигают беззнаковое слово `R1:R0` влево на 1–4 разряда. При переполнении общая ветвь `A3A7` записывает `0xFFFF`. Варианты на 1–3 разряда отражают переполнение в `CY`, вариант на 4 разряда сохраняет исходный `CY`. |
| `CODE:A3D9`, `A3E1`, `A3ED` | `shift_right_u16_1`, `shift_right_u16_2`, `shift_right_u16_3` | Логический сдвиг слова `R1:R0` на 1, 2 или 3 разряда. В `CY` остаётся последний вытесненный бит. Примеры вызовов по `0D07`, `1856` и `167C`. |
| `CODE:A3F9`, `A400` | `add_u16_register_pairs`, `subtract_u16_register_pairs` | Складывают или вычитают `R3:R2` из `R1:R0` с записью результата в `R1:R0`. Перенос или заём возвращается в `CY`. Вызов по `19D1` сразу проверяет заём. |
| `CODE:A412–A428` | `saturate_stock_i16_to_i8` | Сужает знаковое слово `R1:R0` до диапазона −128…127, возвращает байт в `A` и сохраняет `CY`. Вызывается по `9EA0`. |
| `CODE:A429–A42E` | `abs_accumulator_i8` | Если установлен `ACC.7`, инвертирует `A` и прибавляет единицу. На входе и выходе используется `A`, перенос сохраняется, `0x80` остаётся `0x80`. Вызовы есть по `15FC`, `19F4`, `37EB`. Реализация на C. |
| `CODE:A42F–A43D` | `abs_stock_i16` | Возвращает модуль знакового слова в `R1:R0` и его старший байт в `A`. Для `0x8000` возвращает беззнаковое `0x8000`. Прямые вызовы есть по `BE13`, `BE37`, `BE54`, `BE64`. |
| `CODE:A43E–A4DB` | `apply_iac_airflow_target`, `convert_iac_airflow_to_position` | При открытом дросселе устанавливает смещение `F977` из верхней границы адаптации плюс 5 шагов. При закрытом дросселе и оборотах от порога `F848` устанавливает верхнюю границу без добавки. Ниже порога уменьшает прежнее смещение на шаг каждые 5 тактов, используя штатное ограничение по знаку. Для перевода расхода в шаги ограничивает расход, умножает его на коэффициент Q7 и прибавляет смещение. Сумма приводится к байту по модулю 256 перед ограничением до 120 шагов и записью в `IRAM:64`. [Режим холостого хода, стр. 34–35](../docs/ctp321.pdf#page=34) |
| `CODE:A4DC–A574` | `apply_poststart_iac_airflow`, `reset_poststart_iac_offset`, `convert_poststart_iac_airflow` | По температурному индексу `IRAM:4E` выбирает нижнюю и верхнюю границы смещения `F94C` и период его уменьшения. Перед ограничением сравнивает уменьшенное значение с физическим байтом `IRAM:00`. При равенстве сбрасывает бит `54`. Ограничители при этом берут границы из текущего банка регистров. Точка `A524` принимает смещение в аккумуляторе и сбрасывает счётчик `F94B`. Итоговый предел положения берётся из `5F62` при сырой температуре не выше `5F63`, иначе из `6082`. [Переход из пуска, стр. 32](../docs/ctp321.pdf#page=32) · [Ограничение положения РХХ, стр. 35](../docs/ctp321.pdf#page=35) |
| `CODE:2BCD–2BE5` | `update_rpm_axis` | Индекс из таблицы `CODE:613C` записывается в `IRAM:57`, затем округляется до половины интервала оси в `IRAM:58` и до целого интервала в `IRAM:59`. Билинейная интерполяция читает `IRAM:57` по `3833`. Выполнение продолжается по `2BE6`. |
| `CODE:2C3F–2C6B` | `update_knock_noise_zone` | Квантование ДПДЗ выбирает строку таблицы `CODE:7AC7`, округлённый индекс оборотов выбирает столбец. Полный байт записывается в `XDATA:F933`, младшая тетрада с номерами зон в `XDATA:F932`, индекс строки в `XDATA:F979`. Бит `37` получает признак адаптации при сброшенном бите `62`. Выполнение продолжается по `2C6C`. |
| `CODE:3396–33C1` | `update_coolant_axis` | Блок C записывает в `IRAM:4E` округлённый индекс с ограничением до 36. Перед делением сумма сырого кода и 2 ограничена разрядностью байта. С `33A7` вычисляются координаты для интерполяции. Выполнение продолжается по `33C2`. |
| `CODE:280E–2817` | `set_warmup_duration` | Выбирает длительность прогрева из таблицы `8508` по температурному индексу и записывает её в `XDATA:F878`. Выполнение продолжается по `2818`. |
| `CODE:3F74–3F94` | `update_idle_or_economy_mixture` | Бит `59` выбирает температурную кривую состава смеси ХХ `87E4`. При сброшенном бите код интерполирует карту экономичного режима `6613` по оборотам и цикловому наполнению. Результат сохраняется в `IRAM:60`. |
| `CODE:3F95–3FAC` | `update_base_ignition` | Бит `02` выбирает карту `6AC8` или `6BC8`. Бит `0x04` в `IRAM:7A` сохраняет прежний УОЗ в `IRAM:62`, иначе туда записывается результат билинейной интерполяции. |
| `CODE:3FAD–3FBA` | `update_injection_phase` | Записывает значение карты `64D3` в `IRAM:4D` по индексу `IRAM:5F`. Бит `0x02` в `IRAM:7A` сохраняет ранее записанную фазу. Выполнение продолжается по `3FBB`. |
