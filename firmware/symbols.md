# Символы J5V05L19

Для подтверждённых имён записываем адрес, инструкцию или ссылку из кода и, где применимо, калибровку и раздел руководства. Для гипотез указываем адрес в имени и какой факт нужен для подтверждения. Все адреса `CODE` соответствуют смещениям в штатном BIN.

## Подтверждённые участки

| Адрес | Имя | Основание |
|---|---|---|
| `CODE:0000` | `reset_vector` | Инструкция `LJMP` ведёт к `reset_entry_204d`. |
| `CODE:0003`, `001B`, `0023`, `006B` | `irq_vector_0003`, `irq_vector_001b`, `irq_vector_0023`, `irq_vector_006b` | Векторы переходят на `078C`, `04B4`, `5A25`, `0119` соответственно. `0023` — вектор UART0. |
| `CODE:000B`, `0013`, `002B`, `0043`, `004B`, `0053`, `005B`, `0063`, `0083`, `0093`, `009B`, `00A3`, `00AB` | `irq_unused_<адрес>` | Каждый вектор выполняет ровно один `RETI`. SDCC генерирует его из пустой функции C с атрибутом `__interrupt`. |
| `CODE:A59D–A5FE` | `interp_bilinear_u8` | Два индекса 4.4 в `R2` и `R3`, указатель на таблицу в `DPTR`, сырой результат в `A`. Вызовы по `383F` и `3FA8` используют базовое цикловое наполнение и таблицы экономичного либо соседнего варианта УОЗ. |
| `CODE:A611–A62E` | `interp_curve_u8` | Индекс в `R2`, дробная часть в `R3`, указатель в `DPTR`, результат в `A`. Вызов по `42A0` использует кривую желаемых оборотов ХХ. Возрастающая и убывающая ветви округляют по-разному. |
| `CODE:A33A`, `A346` | `minimum_u16_register_pair`, `maximum_u16_register_pair` | Беззнаковое сравнение `R3:R2` с `R1:R0` и запись минимума или максимума в `R1:R0`. `CY` хранит заём от сравнения. Вызовы по `17B3` и `2EB9` используют результат при записи в XDATA. |
| `CODE:A381`, `A389` | `negate_u16_register_pair`, `negate_u24_register_triple` | Два или три последовательных вычитания с заёмом вычисляют отрицание по модулю разрядности, начиная с `R0`. Для 16-битного варианта есть вызовы по `0FC6` и `2E6E`. Для 24-битного варианта прямой вызов пока не найден. |
| `CODE:A394`, `A408` | `sign_extend_i24_register_triple`, `sign_extend_i8_register` | Знак старшего входного байта расширяется в следующий регистр. По `A05F` из `R2` формируется `R3` для 16-битного сложения сразу следом. По `9F55` расширяется `R0` в `R1` перед умножением. |
| `CODE:A3F9`, `A400` | `add_u16_register_pairs`, `subtract_u16_register_pairs` | Складывают или вычитают `R3:R2` из `R1:R0` с записью результата в `R1:R0`. Перенос или заём возвращается в `CY`. Вызов по `19D1` сразу проверяет заём. |
| `CODE:A429–A42E` | `abs_accumulator_i8` | Если установлен `ACC.7`, инвертирует `A` и прибавляет единицу. На входе и выходе используется `A`, перенос сохраняется, `0x80` остаётся `0x80`. Вызовы есть по `15FC`, `19F4`, `37EB`. Реализация на C. |
| `CODE:2BCD–2BE5` | `update_rpm_axis` | Индекс из таблицы `CODE:613C` записывается в `IRAM:57`, затем округляется до половины интервала оси в `IRAM:58` и до целого интервала в `IRAM:59`. Билинейная интерполяция читает `IRAM:57` по `3833`. Выполнение продолжается по `2BE6`. |
| `CODE:3396–33C1` | `update_coolant_axis` | Блок C записывает в `IRAM:4E` округлённый индекс с ограничением до 36. Перед делением сумма сырого кода и 2 ограничена разрядностью байта. С `33A7` вычисляются координаты для интерполяции. Выполнение продолжается по `33C2`. |
| `XDATA:F887`, `F888` | `idle_temp_index`, `idle_temp_fraction` | Индекс ограничен сверху числом 36. Дробная часть равна остатку от деления сырого кода температуры на 5, умноженному на 51. Перед вызовом по `42A0` обе координаты загружаются для интерполяции желаемых оборотов. [Холостой ход, стр. 32–33](../docs/ctp321.pdf#page=32) |
| `CODE:CD7C–CD7E` | `set_flag_2f_4_cd7c` | `SETB` устанавливает бит 4 в `IRAM:2F`, затем `RET`. Сюда ведут переходы по `CCE7` и `CCFB`. Реализация на C. |
| `CODE:D2F1–D2F3` | `set_flag_2f_7_d2f1` | `SETB` устанавливает бит 7 в `IRAM:2F`, затем `RET`. Сюда ведёт переход по `321B`. Реализация на C. |
| `CODE:F090–F093` | `select_data_pointer_zero` | `MOV 92h,#0` выбирает набор регистров указателя 0 через `DPSEL`, затем `RET`. Входящие вызовы есть по `269D`, `3247`, `3B11`. Реализация на C. |
| `CODE:F275–F277` | `clear_flag_21_0_f275` | `CLR` сбрасывает бит 0 в `IRAM:21`, затем `RET`. Сюда ведут переходы по `F07C`, `F0D8`, `F173` и `F272`. Реализация на C. |
| `CODE:60C7`, `60C8` | `fan_off_temperature`, `fan_on_temperature` | Карта 0738 и чтения по `4B2F` и `4B38` дают пороги выключения и включения вентилятора. Два C-значения в градусах кодируются как `T + 40`. |

## Сверка карт и руководства

Адреса и подписи взяты из обычной карты [0738](../bins/J5V05L19_738.j5). Для каждой строки найдена запись с теми же типом, ID и размерами в обычной карте [0923](../bins/J5v05l19_0923.j5). Смещения записей начинаются с их заголовков CTM.

| Калибровка | CODE и ID | Сопоставление | Где читать алгоритм |
|---|---|---|---|
| Желаемые обороты | `6F56`, `D51CF610` | Кривая `desired_idle_rpm` в C из 39 точек, температура ОЖ → обороты. CTM `633D` в 0738, `6047` в 0923. `MOV DPTR,#0x6F56` по `429D`. | [Холостой ход, стр. 32–33](../docs/ctp321.pdf#page=32) |
| Базовое цикловое наполнение | `75EF`, `4E7F9E27` | Таблица `base_cylinder_charge_raw` в C размером 16 × 16, обороты и положение дросселя → мг/цикл. CTM `C3A6` и `BAEB`. `MOV DPTR,#0x75EF` по `383C`. | [Расчёт циклового наполнения, стр. 45](../docs/ctp321.pdf#page=45) |
| УОЗ для экономичного режима | `6AC8`, `3228799F` | Таблица `economy_ignition_half_degrees` в C размером 16 × 16, обороты и цикловое наполнение → градусы поворота коленвала. CTM `CC2C` и `C32E`. `MOV DPTR,#0x6AC8` по `3F95`. | [УОЗ в рабочих режимах, стр. 43](../docs/ctp321.pdf#page=43) |
| Квантование оборотов | `613C`, `A779A453` | 256 байт `rpm_quantization_q4` в C. CTM `1886A` и `1731C`, указатель загружается по `2BCD`. Соседний массив `rpm_breakpoints` по `623C` содержит 16 слов с точками оси. | [Ось УОЗ и её точки](../docs/calibrations.md#контрольная-ячейка-экономичного-уоз) |
| Подача топлива на пуске | `710B`, `7592956F` · `7152`, `21D35BE1` · `7179`, `852388F5` | Малая, асинхронная и большая подачи по 39 точек. CTM `3DC8` / `3CF9`, `3BD5` / `3B1E`, `3FBB` / `3ED4`. Указатели загружаются по `1A3B`, `3DEA` и `1B0D`. | [Пуск, стр. 30](../docs/ctp321.pdf#page=30) |
| Коррекция по RPM на пуске | `7132`, `547F7F3E` | 32 точки. CTM `41AE` и `40AF`, указатель загружается по `1A50`. | [Пуск, стр. 30](../docs/ctp321.pdf#page=30) |
| УОЗ на пуске и время накопления | `71A0`, `19A78759` · `71C8`, `47E275C8` | 40 и 16 точек. CTM `4B63` / `49C6` и `1686D` / `155B3`. Указатели загружаются по `3D76` и `071E`. | [Зажигание на пуске, стр. 31](../docs/ctp321.pdf#page=31) |
| Динамическая производительность форсунки | `71D8`, `E226DB35` | 16 точек поправки времени впрыска по напряжению. CTM `13E3B` и `12EC6`, указатель загружается по `28AD`. | [Расчёт топливоподачи, стр. 36](../docs/ctp321.pdf#page=36) |
| Максимальное смещение УОЗ при детонации | `71E8`, `5FAE0FA7` | 32 точки. CTM `E134` и `D73D`, указатель загружается по `5642`. | [Регулирование УОЗ при детонации, стр. 48](../docs/ctp321.pdf#page=48) |
| Квантование ДПДЗ | `7208`, `21B373DD` | 101 байт `throttle_quantization_q4`. CTM `14553` и `1356C`, базовое наполнение использует эту таблицу по `3835`. | [Расчёт циклового наполнения, стр. 45](../docs/ctp321.pdf#page=45) |
| Тарировка ДМРВ | `99B9`, `9D2BE229` | 256 байт `maf_transfer_raw`. CTM `185CD` и `170AB`. Специальный адрес карты `FFFFFF96` разрешается по инструкции загрузки указателя в `06DC` перед `MOVC`. | [Специальные адреса карт](../docs/calibrations.md#специальные-адреса-и-код-редактора) |

Формат значений в карте описывает представление в редакторе. В частности, УОЗ показывается как знаковое значение, а `interp_bilinear_u8` обрабатывает сырые байты как беззнаковые. [Разбор карт J5](../docs/calibrations.md#кривые-и-таблицы-в-0738)

## Рабочие гипотезы и следующий разбор

| Адрес | Предложенное имя | Критерий подтверждения |
|---|---|---|
| `IRAM:0049` | `coolant_temp_raw_49` | Значение используется при расчёте индекса температурной кривой ХХ. Проследить все записи в этот байт до преобразования показания ДТОЖ. |
| `IRAM:0062` | `ignition_lookup_raw_62` | В байт записывается результат интерполяции ветви УОЗ по `3FAB`. Проследить последующие чтения и установить, к какому промежуточному значению относится байт после переключения таблиц. |
| `IRAM:002F` (бит 4) | `diagnostic_reply_ready_2f_4` | Одна ветвь перед установкой флага загружает указатель на диагностический ответ `CODE:C852`. Проверить назначение всех установок и сбросов флага и место начала передачи. |

Для ветвей пуска, перехода на ХХ и рабочей топливоподачи начинать с поиска обращений к калибровкам одноимённых групп J5. Сопоставлять ветвления, флаги комплектации и масштаб арифметики с руководством. Описание Январь‑5 задаёт рабочие гипотезы для L19. Например, раздел диагностики прямо отмечает, что часть флагов зависит от версии ПО и норм токсичности.
