# Январь 5.1 — документация для открытой прошивки

Исходные материалы проекта находятся в [`bins/`](../bins/). Три 64-КиБ образа побайтно совпадают с файлами в архивах SMS-Soft. `J5V05L19` относится к Январю 5.1 `2112-1411020-41` с фазированным впрыском, `J5V13I02` — к Январю 5.1.1 `2111-1411020-71` с одновременным впрыском. `J5v05l19a.bin` — опубликованный вариант `J5V05L19` с отключённым контролем ПЗУ. Для сравнения штатного поведения пары `-41` и `-71` используются соответственно `J5v05l19.bin` и `J5v13i02.bin`. Копии, созданные в Chip Tuning Pro 3.21.0738, описаны в [разборе сохранения](firmware.md#сохранение-в-chip-tuning-pro-321). [Каталог SMS-Soft](https://almisoft.ru/romecuvaz_j5.htm)

Редактор поддерживаемых BIN и Rust-библиотека находятся в каталоге `editor/`. [Запуск и публичный API](../editor/README.md)

| Документ | Содержание |
|---|---|
| [Аппаратура](hardware.md) | Модификации, обе принципиальные схемы, отличия контактов и сигналы на выводах C509 |
| [Дампы и карта памяти](firmware.md) | Идентификация, векторы, проверка Flash, чтение таблиц и интерполяция в C509 |
| [Карты калибровок](calibrations.md) | Дерево записей обеих сборок, размеры таблиц, адреса в BIN и выгрузка JSON |
| [Диагностика и программирование](diagnostics.md) | Спецификации ВАЗ для R83 и Евро‑2, K-Line, подключение стенда и проверка восстановления |
| [План разработки](development.md) | Инструменты C509, подсистемы ЭСУД, порядок реализации и стендовые проверки |

В таблицах аппаратуры приведены данные опубликованных схем. Адреса и суммы в разборе дампов получены непосредственно из локальных файлов. Для неизвестных полей отмечено, чем их можно подтвердить. Физического ЭБУ и стендовых трасс в материалах проекта пока нет. Внешние оригиналы доступны по прямым ссылкам рядом с результатами разбора.
