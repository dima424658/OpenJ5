# Редактор прошивок Январь 5.1

Приложение на Rust и egui для редактирования 64-КиБ образов J5V05L19, J5V13I02 и J5V07G26. При запуске открывается пример L19. Можно выбрать другой BIN в диалоге, перетащить его в окно или передать первым аргументом.

```sh
cd editor
cargo run -p janvar-editor-desktop --locked
cargo run -p janvar-editor-desktop --locked -- ../bins/J5v13i02.bin
```

Меню «Файл», «Правка» и «Вид» находится в системной строке меню на macOS и в окне редактора на Windows и Linux. Команда выхода запрашивает подтверждение при несохранённых правках.

- **Отменить правку** — `⌘Z` на macOS, `Ctrl+Z` на Windows и Linux.
- **Повторить правку** — `⌘⇧Z` на macOS, `Ctrl+Shift+Z` на Windows и Linux.
- **Сохранить** — `⌘S` на macOS, `Ctrl+S` на Windows и Linux.
- **Сохранить как…** — `⌘⇧S` на macOS, `Ctrl+Shift+S` на Windows и Linux.
- **Переключить вид** — `D` между таблицей и графиком 2D или поверхностью 3D. Во время ввода текста клавиша работает в поле ввода.

В таблице щёлкните по ячейке, затем по противоположному углу с зажатой `Shift`, чтобы выделить прямоугольный блок. `Esc` снимает выделение. `⌘C` / `Ctrl+C` копирует выбранные ячейки, `⌘V` / `Ctrl+V` вставляет числа с табуляцией или пробелами между столбцами и переносами между строками. Вставка начинается с левой верхней ячейки выделения или с `(0, 0)`. Блок должен целиком помещаться в таблицу. Вся вставка отменяется одним действием.

## Калибровки

| Тип | Данные и действия |
|---|---|
| Список строковых параметров | **Паспорт прошивки** в начале дерева калибровок. Номер блока, тип двигателя, идентификатор и дата ПО, аппаратный и программный номера ЭБУ от поставщика |
| Список чекбоксов | Флаги комплектации и диагностические маски. Отметка соответствует установленному биту |
| Таблица 2D | Желаемые обороты ХХ по температуре. По умолчанию открывается строка значений. График доступен через **Вид → График 2D** |
| Таблица 3D | Экономичный УОЗ. Цветная сетка и вращаемая поверхность с общим выбором ячейки |
| Таблица 1D | Числовая калибровка в одной ячейке. Например, температура включения вентилятора |

Остальные числа, кривые и поверхности открываются по описанию из карты. Для преобразований, которые ещё не восстановлены, редактор явно показывает сырые значения. Если запись карты ссылается на адрес, который не удаётся разрешить в BIN, редактор показывает **Адрес не найден**.

Строковые поля паспорта имеют фиксированные слоты ASCII. Поле «Идентификатор ПО в паспорте» расположено отдельно от идентификатора профиля BIN по `0x6020`. Флаги меняются по одному биту. Паспорт и флаги входят в историю правок и в список несохранённых изменений.

После ввода число округляется до ближайшего доступного значения калибровки. Значения за пределами диапазона ограничиваются ближайшей границей. Это правило действует и для групповых правок. Значение выбранной точки меняется в панели свойств. Двойной щелчок помещает курсор в поле значения. Для кривой и таблицы раздел **Все точки** позволяет задать общее значение или сдвинуть значения на величину или процент. Групповая операция отменяется одним действием. Принципы редактирования кривых и поверхностей описаны в справке CTP. [Кривые, стр. 10](../docs/ctp321.pdf#page=10) · [Поверхности, стр. 14](../docs/ctp321.pdf#page=14)

Для УОЗ способ смешивания знаковых байтов в ЭБУ описан в разборе прошивки. [Разбор интерполяции](../docs/firmware.md#чтение-калибровочных-таблиц)

Для L19 и I02 встроена карта 0738. Для G26 и других образов Январь 5.1 положите карту 0738 рядом с BIN или откройте её через **Открыть J5**. Имя карты должно начинаться с идентификатора ПО в BIN, например `J5V07G26.j5` или `J5V07G26_0738.j5`. Затем можно открыть соответствующую карту 0923. Недостающие адреса и преобразования 0923 берутся из 0738 после сверки ID и размеров. Для других версий BIN доступен просмотр. Редактор разрешает сохранение для версий с проверенной схемой контрольных сумм. [Разметка и форматы CTM](../docs/calibrations.md)

У специальных адресов источником служит сам BIN. Например, три кривые реле стартера открываются только при наличии маркера `SMSSwS`. Подписи и координаты осей берутся из карты. Если координаты ещё не восстановлены, график показывает номера узлов. Для кривых можно переключаться между полным диапазоном Y и диапазоном текущих значений.

## Защита и сохранение

Раздел **Защита калибровок** различает штатные инструкции L19, изменение CTP 0738 из `no-sec.bin` и вариант L19a. Редактор может применить изменение CTP к штатному образу и восстановить штатные инструкции для обоих известных вариантов. Диагностика P0601 и принудительная установка бита комплектации входят в эту операцию. Привязка к EEPROM и защита от считывания относятся к отдельным механизмам. [Руководство CTP, стр. 21](../docs/ctp321.pdf#page=21) · [Привязка к EEPROM, стр. 22](../docs/ctp321.pdf#page=22)

Команда **Сохранить** перезаписывает текущий BIN. Для встроенного примера она предлагает выбрать путь. Команда **Сохранить как…** записывает BIN по выбранному пути и делает этот файл текущим. При записи пересчитываются общая сумма Flash и, для L19, суммы двух проверяемых областей калибровок. Проверка результатов выполнена на BIN из репозитория. [Алгоритмы контрольных сумм](../docs/firmware.md#проверки-целостности) · [Серийные суммы, стр. 61](../docs/ctp321.pdf#page=61)

## Подключение библиотеки

Workspace разделён на библиотеку `janvar-editor` и приложение `janvar-editor-desktop`. Пакет приложения зависит от библиотеки по её публичному API. egui, файловые диалоги и встроенные примеры находятся в desktop-пакете.

```toml
[dependencies]
janvar-editor = { path = "../janvar/editor" }
```

```rust
use janvar_editor::firmware::{self, Parameter, SaveMode};
use std::path::Path;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut image = firmware::open(Path::new("original.bin"))?;
    image.set(Parameter::FanOn, 0, 102.0)?;
    image.save(Path::new("edited.bin"), SaveMode::Create)?;
    Ok(())
}
```

`Image::passport()` и `Image::set_passport()` читают и редактируют поля паспорта. `Image::flag()` и `Image::set_flag()` работают с битами известных групп. `Entry::flags` содержит подписи, адреса и номера битов из J5.

`Entry::numeric()` разрешает адрес и возвращает калибровку для чтения и записи чисел и ячеек независимо от интерфейса.

`Image::to_bin()` возвращает изменённый образ с пересчитанными суммами в памяти. `Image::reading()` возвращает физическое значение, исходный байт и сохранённое значение. Для J5 используйте `Catalog::parse()`, `Catalog::build()` и, при наличии подходящего эталона 0738, `Catalog::with_reference()`.

## Код и проверки

- [firmware.rs](src/firmware.rs) читает и сохраняет BIN, определяет профиль, управляет историей и рассчитывает контрольные суммы.
- [calibration.rs](src/firmware/calibration.rs) описывает адреса, размеры, единицы и кодирование. [rom.rs](src/firmware/rom.rs) определяет варианты защиты L19.
- [j5.rs](src/j5.rs) читает CTM и сопоставляет карты двух форматов.
- [desktop/src/ui](desktop/src/ui/) содержит отдельные компоненты для чисел, кривых, сеток и 3D-поверхностей.

```sh
cargo fmt --all --check
cargo clippy --workspace --locked --all-targets -- -D warnings
cargo test --workspace --locked
cargo test -p janvar-editor --locked
```
